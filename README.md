# AMG · Drive personal

Cada usuario configura su perfil y autoriza la creación de una hoja en su propio Google Drive.
Publica docs con GitHub Pages: main /docs. Configura docs/config.js con el cliente OAuth y la URL /exec del backend V7.
Activa Google Drive API y Google Sheets API en el proyecto del cliente OAuth.
El backend completo y la guía están en el paquete de instalación. V7 sustituye el backend central de V6.
No subas copias de datos, tokens ni client secrets al repositorio.
